# Asset inventory

Every image on the website, where it comes from, and the label it carries on the page. The label tells visitors what kind of image it is: render, mockup, final artwork, a third-party work, and so on.

- **Originals are untouched.** The PDFs stay in `source-material/pdfs/`. The 32 images attached to the brief were **copied** to `source-material/images/<project>/` with descriptive names (mapping below).
- **Crops from PDFs** are generated into `source-material/_extracted/` by `npm run assets:extract`. That folder is derived and git-ignored; regenerate it any time.
- **Web versions** are generated by `npm run assets:build` into `public/assets/` as AVIF and WebP at 480 / 800 / 1200 / 1800 / 2400 px (never upscaled). Each one has a blurred placeholder and explicit dimensions in `src/data/assets.generated.json`.
- **Social cards** (1200×630) are in `public/og/`.
- To regenerate this table: `node scripts/inventory.mjs`.

## Image types and their labels

| `kind` | Label on site | Meaning |
|---|---|---|
| `render` | Render 3D | 3D visualisation made by Iván (Esko Studio) |
| `mockup` | Mockup | Design placed into a photographic mockup template |
| `flat` | Arte final | Final artwork: labels, dielines, pages, posters |
| `process` | Proceso | Screenshot of the working process |
| `manual` | Página del manual | Section of a brand manual |
| `ambient` | Ambientación | Presentation scene of uncertain origin (possibly AI-generated or composited). **To confirm** |
| `ai` | Imagen generada con IA | Confirmed AI image (none in use yet; switch `ambient` → `ai` once confirmed) |
| `reference` | Obra de terceros | Someone else's work (Lubalin's pieces, moodboard brands) |
| `art-direction` | Referencia de dirección fotográfica | Example photos used to define photographic direction (authorship unknown) |
